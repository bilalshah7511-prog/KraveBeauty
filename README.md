# KraveBeauty Checkout Demo

Vite + React checkout skin for [KraveBeauty](https://kravebeauty.com).

## Font

**Basis Grotesque Medium Pro only** (`public/fonts/basis-grotesque-medium-pro.ttf`). No other typefaces.

## Run

```bash
npm install
npm run dev
```

## Promo

- `KRAVE10` — 10% off
- `SAVE20` — $20 off
- `FREESHIP` — free shipping

Free shipping on orders $50+.
